# Welcome to the Steal a Superpower Wiki

This is an **independent, fan-made** guide to **Steal a Superpower** on Roblox. We are building an English-first reference that players can use to find practical information without mixing it with other games.

## Where to start

- **[Guides](/guides/)** — New-player resources and explanations of game systems.
- **[Codes](/codes/)** — Code information. We will label codes as active only when verified.
- **[Powers](/powers/)** — Superpower reference pages, with unverified details clearly identified.
- **[Bosses](/bosses/)** — Encounter reference and pending verification.
- **[Upgrades](/upgrades/)** — Upgrade information and research status.
- **[Base](/base/)** — Base-related reference and research status.
- **[Updates](/updates/)** — Confirmed game update notes.

## Our verification policy

We do not publish untested codes, invented superpowers, unsupported statistics, or patch claims as established facts. Game content may change after updates. Pages will be expanded with sources and last-checked dates as information is confirmed.

## What's coming next?

We plan to document beginner progression, individual superpowers, useful strategies, verified codes, and item information. This is a starting page rather than a finished gameplay walkthrough.

*This site is not affiliated with Roblox or the game developers.*
