## How to redeem Steal a Superpower codes

1. Open **Steal a Superpower** on Roblox.
2. Find the **Codes** button in the game interface (guides place it near the top-right).
3. Enter the code exactly as written, including capitalization.
4. Select **Redeem** and check the message and rewards in your game.

Codes may expire or stop working without warning. If a code fails, check its spelling and whether you have already redeemed it.
